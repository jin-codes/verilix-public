02 · 연결

늘 쓰던 AI 도구에서, 그대로무료

verilix의 지식 베이스를 평소 쓰는 대화형 AI에 연결하세요. 서버 주소 하나면 됩니다. 연결과 사용에 별도 요금은 없습니다.

search_knowledge

질문하면 쌓아둔 문서 중 관련된 것을 찾아 답에 활용합니다. 그 주제에서 파악된 당신의 숙련도·관심의 결도 배경으로 함께 전달돼, 답의 깊이와 난이도가 맞춰집니다.

save_document

그 자리에서 나눈 대화를 새 문서로 저장합니다. 제목·요약·결론·배운 점·태그까지 정리해서 — 다음에 어디서든 이어볼 수 있게.

OAuth를 지원하는 도구는 서버 주소만 붙여넣으면 브라우저 로그인으로 바로 연결됩니다. API 키를 직접 넣는 방식도 지원합니다.

연결된 AI 도구
› search_knowledge({ query: "지난번 로드맵 정리 기준" })
✓ 관련 문서 3건 — "프로젝트 방향 정리", "우선순위 트레이드오프" …
  + 배경: 이 주제에서 사용자 숙련도 = 중급
 
› save_document({ title: "3분기 로드맵 확정", … })
✓ 새 문서로 저장됨 — 태그 3개 · 요약 · 결론 포함

04 · 개인화

조용히 배우고, 조용히 돕습니다

대화가 쌓이면 verilix는 주제별로 당신의 숙련도와 관심의 결을 정리해 둡니다. 이 배경은 다음 세션에서 답의 눈높이를 맞추는 데에만 쓰입니다.

시스템 설계중급
트레이드오프 어휘에 익숙함. 구체적 실패 사례를 예시로 들면 대화가 빨라진다.
철학고급
1차 문헌을 직접 인용함. 입문 설명은 건너뛰고 바로 논점으로.
임베딩 검색초급
개념을 잡아가는 중. 수식보다 비유가 잘 먹힌다.

개인화 메모는 당신을 위한 배경일 뿐, 대화 상대에게 먼저 늘어놓지 않습니다. 물어보면 무엇을 기록하는지 정직하게 답합니다.
